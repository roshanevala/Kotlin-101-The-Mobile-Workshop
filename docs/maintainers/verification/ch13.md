## Retained-task process restoration and screen observations

A separate reference-app experiment used real UI input for **Coroutines / 2 sessions**, recorded the PID, pressed Home, observed stop/save callbacks, and used `am kill` on that background package. The old PID disappeared. Returning through its **existing Recents card** created a different PID and restored **Coroutines / 2 sessions**.

An earlier shortcut that issued another Activity launch produced a new Activity with defaults instead of resuming that saved instance. The successful check used the retained Recents task, as the learner instructions require. A fresh Activity launch is not interchangeable with task resumption. This experiment establishes one eligible saved-task restoration on the tested runtime, not guaranteed recovery after every process termination or task dismissal.

Portrait and rotation/landscape layouts were inspected using emulator screenshots and UI hierarchy reads. The fixed window helper is shared between variants. This was not an accessibility certification, full device-matrix test, or Compose verification.

## Selected defect and change-request checks

Each defect was independently seeded into the temporary reference; a relevant single selected device test failed, with no errors or skips:

| Defect | Check that detected it |
| --- | --- |
| Omit current topic write | Typing without another action loses its text |
| Omit completed-count write | Recreated count loses progress |
| Treat empty/blank text as absent | Explicitly empty topic incorrectly becomes Kotlin |
| Reset backing count after rendering | The next click after restoration counts from zero |

Enabling widget auto-save while omitting the custom topic write made the typing test pass, reproducing the exercise's masking-bug investigation. Restoring `saveEnabled=false` and the correct reference restores the intended test boundary. These are selected defect checks, not exhaustive mutation coverage.

Changing only the default-topic resource to **KMP** was checked with a temporary instrumented scenario: fresh launch chose KMP, a saved **Coroutines / 1 session** draft retained that value after recreation, and Reset/recreation chose **KMP / 0 sessions**. Restoring sources/resources produced another full 10-test reference pass and lint success.
