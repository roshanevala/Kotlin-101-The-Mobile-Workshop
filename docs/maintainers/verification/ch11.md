## Selected defect checks

Each seeded defect below independently caused a relevant single acceptance test to fail, with no errors or skips:

| Defect | Observable check |
| --- | --- |
| Omit trimming | Source query and emitted state must use normalized text |
| Omit adjacent deduplication | Equal normalized query after completion must not restart source work |
| Omit the quiet-period delay | A rapid burst must search only its final query |
| Convert all source exceptions to failure | Unexpected source exception must escape collection |
| Convert cancellation to failure | Source-created cancellation must not produce error content |
| Filter blank input before replacement | Blank must cancel a running old search and emit idle |
| Use `zip` instead of `combine` | A second progress update must reuse the latest search value |
| Share lazily instead of eagerly | Submission must start source work without a state subscriber |
| Put `debounce` before latest replacement | Old source released after replacement input must not publish during the next quiet period |

The final replacement regression keeps query input open until the new result is observed. This prevents upstream completion from flushing the misplaced debounce and concealing the defect. It uses source-release signals rather than a guessed deadline for the assertion. Restoring the reference produced a full 36-test pass. These are selected defect checks, not exhaustive mutation coverage.

## Lesson programs and changed requests

All **eight** complete lesson programs were run through the documented module route in a temporary working file, with `package workshop.ch11` prepended. Outputs matched for repeated cold work, buffered overlap, latest collector cancellation, replaceable inner quiet periods, independent combination, StateFlow equality, SharedFlow's absent-subscriber behavior, and one eagerly shared upstream.

The changed finite demo printed `Search: [KMP]` and `Progress: 3/5`. The SharedFlow variation with `replay = 1` printed `[Before subscriber]` immediately after the first emission and collected `[Before subscriber, Saved]`, confirming the changed replay behavior.

The lesson distinguishes source-created child cancellation from cancellation of the outer collector. It also keeps source recovery separate from `emit`, explains that `buffer(0)` does not retract delivered values, and avoids claiming every intermediate StateFlow value reaches every collector.
