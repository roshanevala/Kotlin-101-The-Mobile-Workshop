# Chapter 08 Tests and Kotlin pitfalls

Your plan's clone edits the original, and yesterday's history changes when you clear today's list. Write tests that expose the shared data, then repair the ownership boundaries.

Start after [Chapter 07](../07-abstraction-and-dependencies/README.md). You should recognize data classes, copies, mutable and read-only collections, lambdas, and constructor dependencies.
