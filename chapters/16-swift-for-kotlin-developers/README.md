# Chapter 16 Swift for Kotlin developers

Completing a copied study plan changes the original, and a coach stays alive after its owner lets go. Learn enough Swift to explain and repair both behaviors before building the native iOS screen.

Start after [Chapter 15](../15-android-app-architecture/README.md). Bring Kotlin functions, null safety, models, collections, interfaces, and closures; previous Swift experience is unnecessary.

| 2 Practice | [Workshop](WORKSHOP.md) | Repair session input, plan copies, a generic helper, and callback ownership |
| 3 Review | [Solution](SOLUTION.md) | Compare validation, mutation, and release behavior |
