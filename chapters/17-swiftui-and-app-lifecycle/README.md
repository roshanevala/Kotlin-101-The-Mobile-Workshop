# Chapter 17 SwiftUI and app lifecycle

The editor shows a new topic while Save reads an old one. Changing a tip can lose progress, and returning from Home can reset a draft. Give this native Study Lab screen one clear state owner and meaningful scene behavior.

Start after [Chapter 16](../16-swift-for-kotlin-developers/README.md). You should know Swift structs/classes, optionals, protocols, closures, and ARC; previous SwiftUI experience is unnecessary.
